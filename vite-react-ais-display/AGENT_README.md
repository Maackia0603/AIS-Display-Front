# Agent 聊天界面使用说明

## 功能特性

这个React聊天界面仿照了Gradio的结构，提供了以下功能：

### 🎯 核心功能
- **实时聊天**: 支持用户与AI助手的对话交互
- **API集成**: 调用 `http://127.0.0.1:9000/ask` 接口
- **消息历史**: 保存完整的对话记录
- **响应式设计**: 支持桌面和移动设备

### 🎨 界面特色
- **现代化UI**: 使用Ant Design组件库
- **渐变背景**: 美观的视觉设计
- **头像系统**: 用户和AI助手有不同的头像标识
- **时间戳**: 每条消息都显示发送时间
- **加载状态**: 显示AI思考中的状态

### ⌨️ 交互方式
- **回车发送**: 按Enter键快速发送消息
- **Shift+Enter**: 换行输入
- **清空聊天**: 一键清空所有对话记录
- **自动滚动**: 新消息自动滚动到可见区域

## 使用方法

### 1. 启动项目
```bash
# 安装依赖
yarn install

# 启动开发服务器
yarn dev
```

### 2. 访问聊天界面
- 在浏览器中打开 `http://localhost:5173/`
- 点击导航栏中的"智能体"或直接访问 `/agent` 路径

### 3. 开始对话
- 在输入框中输入您的问题
- 按Enter键或点击"发送"按钮
- 等待AI助手的回复

## API接口说明

### 请求格式
```json
POST http://127.0.0.1:9000/ask
Content-Type: application/json

{
  "messages": [
    {
      "role": "user",
      "content": "用户问题"
    }
  ]
}
```

### 响应格式
```json
{
  "content": "AI助手的回复内容"
}
```

## 技术实现

### 前端技术栈
- **React 19**: 使用最新的React版本
- **Ant Design**: UI组件库
- **CSS3**: 现代化样式和动画
- **Fetch API**: 异步HTTP请求

### 状态管理
- **useState**: 管理聊天记录和输入状态
- **useEffect**: 处理副作用和自动滚动
- **useRef**: 引用DOM元素

### 样式特性
- **CSS Grid/Flexbox**: 响应式布局
- **CSS变量**: 主题色彩管理
- **动画效果**: 消息出现和悬停效果
- **媒体查询**: 移动端适配

## 自定义配置

### 修改API地址
在 `src/views/Agent.jsx` 中修改fetch请求的URL：
```javascript
const response = await fetch('你的API地址', {
  // ... 配置
});
```

### 调整样式
在 `src/style/Agent.css` 中修改CSS变量和样式规则。

### 添加新功能
可以在Agent组件中添加更多功能，如：
- 消息搜索
- 对话导出
- 主题切换
- 多语言支持

## 故障排除

### 常见问题
1. **API调用失败**: 检查后端服务状态和网络连接
2. **样式不显示**: 确认CSS文件路径正确
3. **组件不渲染**: 检查React组件导入和路由配置

### 调试方法
- 打开浏览器开发者工具
- 查看Console中的错误信息
- 检查Network标签页的API请求状态
